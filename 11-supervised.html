11  Supervised Learning

Supervised learning uses labeled examples to learn a mapping from input features to outcomes, with the aim of predicting outcomes for new cases. Classification predicts categories, such as spam versus non-spam email or malignant versus benign tumors. Regression predicts numeric outcomes, such as house prices. The statistical models in Chapter 9 already perform these tasks; Chapter 10 places them within the broader learning framework. This chapter develops decision trees, boosted trees, and neural networks, and explains how class imbalance affects classification.

These methods can capture nonlinear relationships and interactions without requiring each one to be specified in a regression formula. That flexibility also makes model evaluation and tuning essential. The examples use two contrasting settings: predicting log house prices with trees and boosting, and learning a nonlinear boundary between two simulated classes with a neural network (Hastie et al., 2009; James et al., 2023).

The classification metrics in Table 9.1 and the discussion that follows it apply to every classifier in this chapter. Accuracy can be misleading when classes are imbalanced; precision, recall, the \(F_\beta\) score, ROC AUC, and probability-based losses answer different questions. Likewise, the cross-validation procedure in Chapter 10 applies to tree depth, the number of boosting rounds, and neural-network settings. Fit preprocessing within each training fold, use validation scores for selection, and reserve test observations for the final evaluation.

11.1 Decision Trees

Decision trees are widely used supervised learning models that predict the value of a target variable by iteratively splitting the dataset based on decision rules derived from input features. The model functions as a piecewise constant approximation of the target function, producing clear, interpretable rules that are easily visualized and analyzed (Breiman et al., 1984). Decision trees are fundamental in both classification and regression tasks, serving as the building blocks for more advanced ensemble models such as Random Forests and Gradient Boosting Machines.

11.1.1 Recursive Partitioning

The core mechanism of a decision tree algorithm is the identification of optimal splits that partition the data into subsets that are increasingly homogeneous with respect to the target variable. At any node \(m\), the data subset is denoted as \(Q_m\) with a sample size of \(n_m\). The objective is to find a candidate split \(\theta = (j, t)\), where \(j\) identifies a feature and \(t\) is its threshold, that minimizes an impurity or loss measure \(H\). A record goes to the left child when its feature value \(x_j\) is at most \(t\), and to the right child otherwise.

When a split is made at node \(m\), the data is divided into two subsets: \(Q_{m,l}\) (left node) with sample size \(n_{m,l}\), and \(Q_{m,r}\) (right node) with sample size \(n_{m,r}\). The split quality, measured by \(G(Q_m, \theta)\), is given by

\[ G(Q_m, \theta) = \frac{n_{m,l}}{n_m} H(Q_{m,l}(\theta)) + \frac{n_{m,r}}{n_m} H(Q_{m,r}(\theta)). \]

The algorithm identifies the best split \(\theta^*\) by minimizing this weighted impurity over candidate splits with nonempty children:

\[ \theta^* = \arg\min_{\theta} G(Q_m, \theta). \]

This process is applied recursively at each child node until a stopping condition is met.

  • Stopping Criteria: The algorithm stops when the maximum tree depth is reached or when the node sample size falls below a preset threshold.
  • Pruning: Reduce the complexity of the final tree by removing branches that add little predictive value. This can reduce overfitting and improve generalization.

11.1.2 Search Space for Possible Splits

At each node, the search space for possible splits comprises all features in the dataset and potential thresholds derived from the feature values. For a given feature, the algorithm considers each of its unique value in the current node as a possible split point. The potential thresholds are typically set as midpoints between consecutive sorted unique values, ensuring a nonempty partition.

Formally, let the feature set be \(\{X_1, X_2, \ldots, X_p\}\), where \(p\) is the total number of features, and let the unique values of feature \(X_j\) at node \(m\) be denoted by \(\{v_{m,j,1}, v_{m,j,2}, \ldots, v_{m,j,k_{mj}}\}\) in increasing order, where \(k_{mj}\) is the number of distinct values. The search space at node \(m\) includes:

  • Feature candidates: \(\{X_1, X_2, \ldots, X_p\}\).
  • Threshold candidates for \(X_j\): \[ \left\{ \frac{v_{m,j,i} + v_{m,j,i+1}}{2} \mid 1 \leq i < k_{mj} \right\}. \]

While the complexity of this search can be substantial, particularly for high-dimensional data or features with numerous unique values, efficient algorithms use sorting and single-pass scanning techniques to mitigate the computational cost.

11.1.3 Classification Criteria

In classification, the split quality metric measures how pure the resulting nodes are after a split. A pure node contains observations that all belong to a single class; a nearly pure node has a dominant class.

  • Gini Index: The Gini index measures node impurity by the probability that two observations independently drawn from the node belong to different classes. A perfect split (all instances belong to one class) has a Gini index of 0. At node \(m\), the Gini index is \[ H(Q_m) = \sum_{k=1}^{K} p_{mk} (1 - p_{mk}) = 1 - \sum_{k=1}^K p_{mk}^2, \] where \(p_{mk}\) is the proportion of samples of class \(k\) at node \(m\) and \(K\) is the total number of classes. The Gini index is often preferred for its speed and simplicity, and it’s used by default in many implementations of decision trees, including sklearn.

    For two equally represented classes, the Gini impurity is 0.5; if all observations have the same class, it is zero. This node impurity differs from the ROC-based Gini discrimination coefficient, defined as twice the ROC AUC minus one (Hastie et al., 2009).

  • Entropy (Information Gain): Derived from information theory, entropy quantifies the disorder of the data at a node. Lower entropy means higher purity. At node \(m\), it is defined as \[ H(Q_m) = - \sum_{k=1}^{K} p_{mk} \log p_{mk}. \] The convention \(0 \log 0 = 0\) handles absent classes. Entropy is commonly used in decision tree algorithms like ID3 and C4.5. The choice between Gini and entropy often depends on specific use cases, but both perform similarly in practice.

  • Misclassification Error: Misclassification error focuses on the most frequent class in the node. It measures the proportion of samples that do not belong to the majority class. Although less sensitive than Gini and entropy, it can be useful for classification when simplicity is preferred. At node \(m\), it is defined as \[ H(Q_m) = 1 - \max_k p_{mk}, \] where \(\max_k p_{mk}\) is the largest proportion of samples belonging to any class \(k\).

11.1.4 Regression Criteria

In regression, the goal is to minimize the spread or variance of the target variable within each node.

  • Mean Squared Error (MSE): MSE is the average squared difference between observed and predicted values (mean of the target in the node). The smaller the MSE, the better the fit. At node \(m\), it is \[ H(Q_m) = \frac{1}{n_m} \sum_{i=1}^{n_m} (y_i - \bar{y}_m)^2, \] where \(y_i\) is the outcome for sample \(i\) in the node and \(\bar{y}_m\) is the mean of its \(n_m\) outcomes. The node mean minimizes squared error. This splitting criterion does not require normally distributed outcomes (Scikit-learn Developers, 2026a).

  • Half Poisson Deviance: Used for count target, the Poisson deviance measures discrepancy between observed counts and their predicted means. At node \(m\), it is \[ H(Q_m) = \frac{1}{n_m} \sum_{i=1}^{n_m} \left[y_i \log\left(\frac{y_i}{\bar{y}_m}\right) - (y_i - \bar{y}_m)\right], \] where \(\bar{y}_m\) is the predicted mean count in the node. The convention \(0 \log(0/\bar{y}_m) = 0\) handles zero counts when \(\bar{y}_m > 0\); a node containing only zeros has impurity zero. This criterion is especially useful when the target variable represents discrete counts, such as predicting the number of occurrences of an event.

  • Mean Absolute Error (MAE): MAE aims to minimize the absolute differences between actual and predicted values. While it is more robust to outliers than MSE, it is slower computationally because evaluating absolute-error splits requires repeated median calculations. At node \(m\), it is \[ H(Q_m) = \frac{1}{n_m} \sum_{i=1}^{n_m} |y_i - \widetilde{y}_m|, \] where \(\widetilde{y}_m\) is the median outcome in the node. The median minimizes absolute error (Scikit-learn Developers, 2026a). MAE gives less weight to large deviations than MSE and can be more robust to outliers.

11.1.5 Ames Housing Example

The Ames Housing data illustrate a regression tree for predicting log house price (De Cock, 2011). Each observation is a house sale. We retrieve the OpenML dataset with ID 42165. This version has 1,460 observations; it is a subset of the larger Ames dataset described in the original article. The response is the natural logarithm of SalePrice, so the prediction errors below are on the log-price scale.

import numpy as np
import pandas as pd
import plotnine as gg

from sklearn.datasets import fetch_openml
from sklearn.model_selection import train_test_split, KFold, cross_val_score

Missing numeric values are filled with training medians; missing kitchen-quality values are filled with the most frequent training category. numeric_features = [

preprocessor = ColumnTransformer([

We compare depths 2 through 10 by five-fold cross-validation on the training records. depths = range(2, 11)

11.2 Gradient-Boosted Models

Gradient boosting is a powerful ensemble technique in machine learning that combines multiple weak learners into a strong predictive model. Unlike bagging methods, which train models independently, gradient boosting fits models sequentially, with each new model correcting errors made by the previous ensemble (Friedman, 2001). While decision trees are commonly used as weak learners, gradient boosting can be generalized to other base models. This iterative method optimizes a specified loss function by repeatedly adding models designed to reduce residual errors.

A fitted ensemble of this type is often called a gradient boosting machine (GBM). Boosting describes the sequential ensemble strategy; gradient boosting specifies how loss gradients determine its updates.

Gradient boosting builds a strong predictor from sequentially fitted weak learners, often shallow decision trees. Each stage uses the loss gradient to identify how the current predictions should change. This provides error correction and accommodates different predictive tasks and loss functions (Hastie et al., 2009).

The effectiveness of gradient-boosted models has made them popular across diverse tasks, including classification, regression, and ranking. Gradient boosting forms the foundation for algorithms such as XGBoost (T. Chen & Guestrin, 2016), LightGBM (Ke et al., 2017), and CatBoost (Prokhorenkova et al., 2018), known for their high performance and scalability.

11.2.1 Gradient Boosting Process

Gradient boosting builds an ensemble by iteratively minimizing the residual errors from previous models. This iterative approach optimizes a loss function, \(L(y, F(x))\), where \(y\) represents the observed target variable and \(F(x)\) the model’s prediction for a given feature vector \(x\). Let \((x_i, y_i)\) denote training example \(i\), for \(i = 1, \ldots, n\), where \(n\) is the training sample size.

Key concepts:

  • Loss Function: Guides model optimization, such as squared error for regression or logistic loss for classification.
  • Learning Rate: Controls incremental updates, balancing training speed and generalization.
  • Regularization: Reduces overfitting through tree depth limitation, subsampling, and L1/L2 penalties.

11.2.1.1 Loss Functions

The loss determines what error each update tries to correct. For a numeric outcome \(y\) and prediction \(F\), half squared-error loss is

\[ L(y, F) = \frac{1}{2}(y - F)^2. \]

Its negative derivative with respect to \(F\) is \(y - F\), the ordinary residual. For a binary outcome coded as \(y \in \{0,1\}\), logistic loss on a log-odds score \(F\) is

\[ L(y, F) = \log(1 + e^F) - yF. \]

Equivalently, after defining the signed label \(s = 2y - 1\), this loss is

\[ L(s, F) = \log(1 + e^{-sF}). \]

The signed-label expression uses \(s \in \{-1,1\}\); inserting a zero-one label into it directly would give the wrong loss. The logistic negative gradient is \(y - \{1 + \exp(-F)\}^{-1}\), so it compares the observed indicator with the fitted probability rather than with the log-odds score. Different losses therefore lead to different pseudo-residuals (Friedman, 2001; Hastie et al., 2009).

11.2.1.2 Model Iteration

The gradient boosting algorithm proceeds as follows:

  1. Initialization: Define a base model \(F_0(x)\), typically the mean of the target variable for squared-error regression or the log-odds of the positive class proportion for binary logistic loss. More generally, choose the constant that minimizes the training loss.

  2. Iterative Boosting: At each iteration \(m = 1, \ldots, M\), where \(M\) is the number of boosting rounds:

    • Compute pseudo-residuals representing the negative gradient of the loss function at the current predictions. For each observation \(i\): \[ r_i^{(m)} = -\left.\frac{\partial L(y_i, u)}{\partial u} \right|_{u=F_{m-1}(x_i)}, \] where \(u\) is the scalar prediction argument of the loss and \(r_i^{(m)}\) is the pseudo-residual for observation \(i\) at round \(m\). The residuals represent the direction of steepest descent in function space, so fitting a learner to them approximates a gradient descent step minimizing \(L(y, F(x))\).

    • Fit a new weak learner \(h_m(x)\) to these residuals. For half squared-error loss, the pseudo-residual is the ordinary residual \(y_i - F_{m-1}(x_i)\); other losses give different gradients.

    • Update the model: \[ F_m(x) = F_{m-1}(x) + \eta \, h_m(x), \] where \(\eta\) is a small positive learning rate (e.g., 0.01–0.1), controlling each update. Smaller learning rates generally require more rounds; they do not guarantee protection from overfitting.

    In some implementations, the update step includes an additional multiplier determined by a one-dimensional line search that minimizes the loss function at each iteration. Specifically, the optimal step length is defined as \[ \gamma_m = \arg\min_\gamma \sum_{i=1}^n L\bigl(y_i,\, F_{m-1}(x_i) + \gamma\, h_m(x_i)\bigr), \] leading to an updated model of the form \[ F_m(x) = F_{m-1}(x) + \eta\, \gamma_m\, h_m(x), \] where \(\eta\) remains a shrinkage factor controlling the overall rate of learning, while \(\gamma_m\) adjusts the step size adaptively at each iteration.

  3. Final Model: After \(M\) iterations, the ensemble model is: \[ F_M(x) = F_0(x) + \sum_{m=1}^M \eta\, \gamma_m\, h_m(x). \]

The final expression includes the line-search multipliers; for the simpler update, set every \(\gamma_m = 1\). In binary classification, \(F_M(x)\) can be a log-odds score, transformed to a probability by the logistic function before classification.

Stochastic gradient boosting is a variant that enhances gradient boosting by introducing randomness through subsampling at each iteration, selecting a random fraction of data points (typically 50%–80%) without replacement to fit the model (Friedman, 2002). This randomness helps reduce correlation among trees, improve model robustness, and lower the risk of overfitting.

11.2.2 Boosting versus Bagging

Boosting and bagging improve prediction by combining multiple fitted models, but they build those models differently. Boosting builds a sequence: each learner depends on the ensemble fitted before it. It focuses on loss gradients, so its correction step depends on the loss rather than always assigning explicit weights to misclassified cases. AdaBoost, gradient boosting, and XGBoost are examples of boosting methods (Hastie et al., 2009).

Bagging, or bootstrap aggregating, fits models independently to bootstrap samples drawn with replacement from the training data. It combines numeric predictions by averaging and class predictions by voting or averaging class probabilities. Independent fits can be computed in parallel. Averaging reduces variance most effectively when the individual models’ errors are not strongly correlated. Random forests extend this idea by also randomizing the features considered at each split; this can further reduce correlation among trees (Hastie et al., 2009).

Aspect Boosting Bagging
Model dependency Learners depend on earlier fits Fits can be made independently
How models differ Each targets remaining loss gradients or errors Each uses a different bootstrap sample
Prediction Additive combination of learners Averaging or voting
Bias and variance Can reduce bias; excessive flexibility can overfit Particularly useful for reducing variance of unstable learners
Computation Stages are sequential Independent fits allow parallel computation
Overfitting Control rounds, learning rate, and learner complexity More averaged fits generally stabilize predictions, but do not remove data or model bias

Both strategies require validation against the same prediction task and baseline. Neither has a universal performance advantage, and neither establishes causal effects simply by predicting well.

11.2.2.1 Random Forests and Bagging Controls

The earlier bagging discussion identifies random forests as an important extension of bagged decision trees. In a random forest, the algorithm considers a random subset of candidate features at each split. This is more specific than choosing a single feature subset for an entire tree: the eligible features can change from node to node. Combined with bootstrap sampling, this randomization helps make the trees’ predictions less correlated (Hastie et al., 2009).

Three controls from that discussion govern different parts of the fit:

  • Number of trees: more trees average over more fitted predictors, usually stabilizing the ensemble at greater computational cost.
  • Number of candidate features: fewer candidates introduce more randomness and may reduce dependence among trees, while weakening an individual tree if useful predictors are often unavailable.
  • Tree depth: depth and minimum leaf size limit the flexibility of each individual tree.

These choices should be assessed using the same validation design as other candidate methods. Feature subsampling does not itself guarantee robustness to missing data; missing-value support depends on the implementation.

11.2.2.2 Adaptive Boosting

Adaptive boosting, or AdaBoost, illustrates a different way to construct an additive ensemble. It changes the weights attached to observations rather than fitting ordinary residuals. Each weak learner is fitted using the current observation weights, and its contribution to the ensemble depends on its weighted prediction error (Hastie et al., 2009).

For binary classification with \(n\) training observations, the procedure starts with equal weights \(1/n\) and repeats the following steps:

  1. Fit a weak learner to the observations using their current weights.
  2. Calculate its weighted classification error and an associated coefficient controlling its contribution to the ensemble.
  3. Add the learner’s weighted contribution to the ensemble score.
  4. Increase the relative weights of observations misclassified by that learner and decrease those correctly classified, then normalize the weights before the next fit.

The final classifier uses the combined scores of the fitted learners. This construction avoids trying to optimize every learner and coefficient at once, although sequential fitting need not find a global optimum. Gradient boosting instead fits learners to negative loss gradients. Its use of a differentiable loss makes the update applicable to regression and other tasks as well as classification. Both methods build sequential ensembles, while bagging fits members independently.

11.2.3 Boosted Trees with Ames Housing

We now apply gradient boosting to the same house-price prediction task, using the same features, preprocessing, training records, and validation folds as the single tree. Keeping these choices fixed lets us compare methods without attributing a different data split to a model improvement. We tune the number of trees while fixing the learning rate at 0.05 and the maximum depth of each tree at 3.

from sklearn.ensemble import GradientBoostingRegressor

n_estimators_list = [50, 100, 200, 400]
gb_model = Pipeline([
    ("pre", preprocessor),
    ("model", GradientBoostingRegressor(
        learning_rate=0.05, max_depth=3, random_state=2026

])
cv_scores_gb = [
    cross_val_score(

        X_train, y_train, cv=cv, scoring="r2"
    ).mean()
    for n in n_estimators_list
]
boost_scores = pd.DataFrame({
    "n_estimators": n_estimators_list, "cv_r2": cv_scores_gb
})

Gradient-boosted trees introduce several parameters that govern model complexity, learning stability, and overfitting control:

  • n_estimators: the number of trees (boosting rounds). More trees can reduce bias but increase computation and risk of overfitting.
  • learning_rate: the shrinkage parameter \(\eta\) controlling the contribution of each new tree. Smaller values (e.g., 0.05 or 0.01) require more trees but often yield better generalization.
  • max_depth: the maximum depth of each individual tree, limiting the model’s ability to overfit local noise. Shallow trees (depth 2–4) are typical weak learners.
  • subsample: the fraction of data used in each iteration. Values below 1.0 introduce randomness (stochastic boosting), improving robustness and reducing correlation among trees.
  • min_samples_split and min_samples_leaf: minimum numbers of observations required for splitting or forming leaves. These control tree granularity and help regularize the model.

In practice, moderate learning rates with a sufficiently large number of estimators and shallow trees are useful starting points, balancing bias, variance, and computational cost.

11.2.4 Stochastic GBM with California Housing

The California housing example illustrates stochastic gradient boosting with subsample=0.7, so each round uses 70% of the training observations, sampled without replacement. This differs from the preceding Ames example’s default subsample=1.0. It preserves the earlier demonstration and its dated seeds, 20250407 for the data split and 20250408 for fitting.

Each observation describes a California census block group. The response is the group’s median house value, expressed in units of 100,000 US dollars; the features summarize income, housing, population, and location. These are area summaries, unlike the individual house sales in Ames (scikit-learn Developers, 2026).

from sklearn.datasets import fetch_california_housing

housing = fetch_california_housing(as_frame=True, data_home=".cache/sklearn")
X_cal, y_cal = housing.data, housing.target

11.2.5 XGBoost: Extreme Gradient Boosting

XGBoost is a scalable implementation of gradient-boosted decision trees (T. Chen & Guestrin, 2016). It builds an ensemble in a stage-wise fashion by minimizing an objective that balances training loss and tree complexity. The framework uses first- and second-order derivatives of the loss to construct updates. Its explicit regularization can penalize both the number of leaves and the size of leaf scores.

XGBoost builds on the same sequential-learning principle as the preceding example, with implementation choices designed for efficient computation, sparse inputs, and missing values. Its learned default directions can route records with missing feature values through a split. These features can be useful for structured data, but they do not guarantee better performance than another implementation (T. Chen & Guestrin, 2016).

Aspect Classical gradient boosting as in the example XGBoost
Loss optimization Fits learners to negative loss gradients Uses gradients and second derivatives in its tree objective
Regularization Learning rate, tree size, subsampling, and other controls These controls plus explicit leaf-weight and tree-complexity penalties
Missing inputs The example imputes values within its pipeline Supports learned default directions for missing values
Computation Sequential boosting rounds Optimizes work within rounds and supports distributed computation
Validation Scikit-learn cross-validation around a pipeline Scikit-learn interface or native cross-validation tools

The table compares specific implementations; it does not imply that all other boosting libraries lack regularization, missing-value handling, or parallel computation. XGBoost still requires choices about the outcome, loss, features, validation design, and tuning. The scikit-learn example above teaches the core learning process without requiring an additional boosting package.

11.3 Handling Imbalanced Data

Handling imbalanced data is a critical task in machine learning, particularly in classification problems where the distribution of instances across the known classes is uneven. This imbalance can significantly bias the model’s training process, leading to poor predictive performance, especially for the minority class. Understanding and addressing this issue is crucial for building models suited to the costs of different prediction errors.

11.3.1 Imbalanced Data

Imbalanced data refers to a situation where the number of observations in one class significantly outweighs those in one or more other classes. This is a common scenario in various domains:

  • In fraud detection, legitimate transactions vastly outnumber fraudulent ones.
  • In medical diagnosis, the dataset might have more negative results (no disease) than positive results (disease presence).
  • In email filtering, spam emails are less common than non-spam.

Such disparities can lead to models that are overly biased towards the majority class when the fitting objective or decision threshold rewards majority-class predictions. Imbalance does not by itself imply that classifying every observation into the majority class is the best rule.

11.3.2 Approaches to Handling Imbalanced Data

  • Resampling Techniques:

    • Oversampling Minority Class: Enhancing the representation of the minority class by replicating instances or generating synthetic samples. SMOTE (Synthetic Minority Over-sampling Technique) is a popular method for creating synthetic samples (Chawla et al., 2002).
    • Undersampling Majority Class: Reducing the size of the majority class to balance the dataset. Careful selection or clustering methods are employed to retain information (Liu et al., 2009).

  • Cost-sensitive Learning: Adjusting the classification cost to make errors on the minority class more impactful than errors on the majority class. This approach often involves modifying the algorithm to be more sensitive to the minority class (Elkan, 2001).

  • Ensemble Methods: Leveraging multiple models to improve classification, particularly of the minority class. Techniques such as Balanced Random Forest (C. Chen et al., 2004) and AdaBoost (Sun et al., 2007) have been adapted for imbalanced datasets.

  • Algorithmic Adjustments: Some algorithms have built-in mechanisms for dealing with imbalanced data, such as adjusting class weights. This is evident in algorithms like SVM and logistic regression, where class weights can be inversely proportional to class frequencies (King & Zeng, 2001).

11.3.3 SMOTE

The Synthetic Minority Over-sampling Technique (SMOTE) offers a nuanced approach to mitigating the challenges posed by imbalanced datasets. Unlike simple oversampling techniques that replicate minority class instances, SMOTE generates synthetic samples in a feature space, enhancing the diversity and representation of the minority class without directly copying existing observations (Chawla et al., 2002).

11.3.3.1 Algorithm

SMOTE’s algorithm can be succinctly described using the following steps for each minority class sample \(x\):

  1. Identify the \(k\) nearest neighbors in the minority class for \(x\).
  2. Randomly choose one of these \(k\) neighbors, call it \(x_{\text{nn}}\).
  3. Generate a synthetic sample \(x_{\text{new}}\) along the line connecting \(x\) and \(x_{\text{nn}}\). Mathematically, \(x_{\text{new}} = x + \lambda (x_{\text{nn}} - x)\), where \(\lambda\) is a random number between \(0\) and \(1\).

This process is repeated until the class distribution is deemed balanced.

In Python, imbalanced-learn implements SMOTE and resampling pipelines. Resampling must occur only on the training records within each cross-validation fold. Applying SMOTE before the split lets information from validation or test observations influence synthetic training points. Keep the validation and test sets at their original class distributions (Imbalanced-learn Developers, 2026).

Synthetic points also depend on the feature representation and distance metric. Scale numeric features appropriately using training data; interpolating arbitrary category codes does not create valid categorical observations. Mixed categorical and numeric data require a method designed for that setting rather than ordinary numeric SMOTE.

11.3.3.2 Applications, Considerations, and Variants

Applications: SMOTE’s approach to enriching datasets by synthesizing new examples has proven beneficial in various fields. For instance, in fraud detection, where fraudulent transactions are rare (Dal Pozzolo et al., 2015), and in medical diagnostics, where certain conditions may be underrepresented in datasets (Johnson & Khoshgoftaar, 2019).

Considerations: While SMOTE enhances the representation of the minority class, it may also lead to overfitting, especially if the minority class is dispersed or if there’s significant overlap with the majority class (Guo et al., 2017). Choosing the right variant of SMOTE and adjusting its parameters requires careful consideration of the dataset’s characteristics.

Advanced Variants: Specific challenges in datasets have led to the development of SMOTE variants like Borderline-SMOTE, which generates samples closer to the decision boundary to improve classifier sensitivity to the minority class (Han et al., 2005). Each variant addresses particular issues, such as noise or the risk of generating ambiguous synthetic samples.

SMOTE and its variants offer a sophisticated approach to mitigating the challenges posed by imbalanced datasets. Through synthetic sample generation, these methods enhance the diversity and representation of the minority class, potentially improving minority-class prediction. Evaluate that benefit rather than assuming resampling improves every metric. The choice of variant and parameters should be guided by the dataset’s characteristics and the problem context, which shows the importance of careful experimentation and validation.

11.4 Neural Networks

Neural networks learn flexible, nonlinear relationships by composing simple computational units. Each unit (or neuron) applies an affine transformation to its inputs followed by a nonlinearity; stacking layers of such units yields a feed-forward mapping from features to predictions. A helpful anchor is logistic regression: it can be viewed as a one-layer neural network with a sigmoid activation. Hidden layers generalize this idea by transforming inputs into progressively more useful internal representations, enabling the model to capture complex patterns beyond linear decision boundaries.

Historically, the field traces back to the early formal model of a neuron by McCulloch & Pitts (1943), followed by Rosenblatt’s perceptron (Rosenblatt, 1958), an early trainable linear classifier. The limitations of single-layer perceptrons, notably their inability to model nonlinearly separable functions, were analyzed by Minsky & Papert (1969). The influential treatment of backpropagation by Rumelhart et al. (1986) renewed the study of neural networks in the 1980s. With the growth of data, advances in hardware, and improved optimization methods, neural networks became the foundation for modern deep learning. With suitable nonlinear activations and enough hidden units, multilayer networks can approximate continuous functions on bounded closed domains. This approximation property does not guarantee that training will find a good predictor. In practice, success depends on architectural design, optimization, and regularization (Hastie et al., 2009).

TipDimensions and Shapes

For an input vector \(x \in \mathbb{R}^d\) with \(d\) features, a hidden layer with \(m\) neurons computes the output \(h = \sigma(Wx + b)\) through an element-wise activation function \(\sigma\), where \(W \in \mathbb{R}^{m\times d}\) and \(b \in \mathbb{R}^m\) are the weight matrix and bias vector. The output layer applies another affine map (and possibly a final activation) to \(h\). Keeping track of these shapes prevents many implementation bugs.

The figure below shows an input layer, one hidden layer, and an output layer with directed connections. (We will formalize the mathematics in the next subsection.)

11.4.1 Structure of a Neural Network

A neural network is composed of layers of interconnected processing units called neurons or nodes. Each neuron receives inputs, applies an affine transformation, and passes the result through a nonlinear activation function. The layers are arranged sequentially so that information flows from input features to intermediate representations and finally to the output.

11.4.2 Mathematical Formulation

Let the input vector be \(x \in \mathbb{R}^{d}\), where \(d\) is the number of features. A hidden layer with \(m\) neurons computes

\[ h = \sigma(Wx + b), \]

where \(h \in \mathbb{R}^m\) is the hidden-layer output, \(W \in \mathbb{R}^{m \times d}\) is the weight matrix, \(b \in \mathbb{R}^{m}\) is the bias vector, and \(\sigma(\cdot)\) is an activation function applied element-wise. Subsequent layers take \(h\) as input and repeat the same computation, producing successively transformed representations. If the output layer contains \(k\) neurons with linear activations, the network computes

\[ \hat{y} = Vh + c, \]

where \(\hat{y} \in \mathbb{R}^k\) is the predicted output, \(V \in \mathbb{R}^{k \times m}\) and \(c \in \mathbb{R}^{k}\) are the output weights and biases. Collectively, these parameters define the model’s trainable structure.

TipFeed-Forward Flow

During a forward pass, inputs propagate layer by layer: \(x \rightarrow h^{(1)} \rightarrow h^{(2)} \rightarrow \cdots \rightarrow \hat{y}\), where \(h^{(l)}\) denotes the output of hidden layer \(l\). Backward propagation of gradients (discussed later) updates all weights based on prediction error.

11.4.3 Network Diagram

Figure 11.4 illustrates a feed-forward neural network with two hidden layers. Arrows indicate the direction of information flow from one layer to the next. Each connection carries a learnable weight, and nonlinear activations transform the signals as they propagate forward.

Note

Each connection (edge) has an associated weight adjusted during training. Here we describe depth by the number of hidden layers, and the width refers to the number of neurons per layer.

For the illustrated connection from input neuron 2 to hidden neuron 3, \(w^{(1)}_{32}\) denotes row 3, column 2 of the first weight matrix. The superscript identifies the layer.

11.4.4 Activation Functions

Activation functions introduce nonlinearity into neural networks. Without them, the entire network would collapse into a single linear transformation, regardless of the number of layers. Nonlinear activations allow networks to approximate arbitrary complex functions, enabling them to model curved decision boundaries and hierarchical representations.

The rectified linear unit (ReLU) is one common activation. Let \(z\) denote the input to a neuron before activation. The most common choices are:

Function Formula Range Key Property
Sigmoid \(\displaystyle \sigma(z) = \frac{1}{1 + e^{-z}}\) \((0,1)\) Smooth, bounded; used in early networks and binary outputs
Tanh \(\displaystyle \tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}\) \((-1,1)\) Zero-centered; saturates at large magnitudes
ReLU \(\displaystyle \mathrm{ReLU}(z) = \max(0, z)\) \([0, \infty)\) Sparse activations; efficient to compute
Leaky ReLU \(\displaystyle \mathrm{LReLU}(z) = \max(0.01z, z)\) \((-\infty, \infty)\) Avoids “dead” neurons of ReLU

Figure 11.5 shows the shape of these activation functions. Notice how ReLU sharply truncates negative values while sigmoid and tanh saturate for large magnitudes.

11.4.5 Training Neural Networks

Training a neural network means adjusting its parameters so that its predictions \(\hat{y}\) align closely with the true outputs \(y\). This is done by minimizing a loss function that quantifies prediction error (Scikit-learn Developers, 2026b). Optimization proceeds iteratively through forward and backward passes.

11.4.5.1 Loss Functions

The choice of loss depends on the task. For \(n\) training observations, let \(y_i\) denote the numeric outcome or binary indicator and \(\hat{y}_i\) the predicted value or probability. For \(K\) classes, let \(y_{ik}\) be one when observation \(i\) belongs to class \(k\), and zero otherwise, and let \(\hat{y}_{ik}\) be its predicted probability for class \(k\). The average losses are:

Task Typical Loss Function Expression
Regression Mean squared error (MSE) \(\displaystyle L = \frac{1}{n}\sum_{i=1}^{n} (y_i - \hat{y}_i)^2\)
Binary classification Binary cross-entropy \(\displaystyle L = -\frac{1}{n}\sum_{i=1}^{n} \left[y_i \log \hat{y}_i + (1-y_i)\log(1-\hat{y}_i)\right]\)
Multiclass classification Categorical cross-entropy \(\displaystyle L = -\frac{1}{n}\sum_{i=1}^{n} \sum_{k=1}^{K} y_{ik}\log \hat{y}_{ik}\)

The loss function \(L(\theta)\) depends on all network parameters \(\theta = \{W, b, V, c, \ldots\}\) and guides the optimization.

11.4.5.2 Gradient Descent

Neural networks are trained by gradient descent, which updates parameters in the opposite direction of the gradient of the loss:

\[ \theta^{(t+1)} = \theta^{(t)} - \eta \nabla_\theta L(\theta^{(t)}), \]

where \(t\) is the iteration number, \(\nabla_\theta L\) is the vector of partial derivatives of the loss with respect to the parameters, and \(\eta > 0\) is the learning rate controlling the step size. Choosing \(\eta\) too small leads to slow convergence; too large can cause divergence.

Variants such as stochastic and mini-batch gradient descent compute gradients on subsets of data to speed learning and improve generalization.

Figure 11.6 gives a two-dimensional analogy of gradient descent. In practice, a neural network may contain millions of parameters, meaning the loss function is defined over an extremely high-dimensional space. The contours shown here use a constructed two-parameter function, with a schematic path to illustrate movement across the surface. The true optimization surface is much more complex, with flat regions, sharp valleys, and numerous local minima, but the intuition of moving “downhill” along the loss gradient remains valid.

11.4.6 Regularization and Overfitting

Because neural networks contain large numbers of parameters, they can easily overfit training data, capturing noise or random fluctuations rather than generalizable patterns. A model that overfits performs well on the training set but poorly on new data. Regularization techniques introduce constraints or randomness that help the network generalize.

11.4.6.1 The Bias–Variance Trade-Off

Adding model complexity (more layers or neurons) can reduce bias while increasing sensitivity to the training sample, as discussed in Chapter 10. The goal of regularization is to find a balance between these forces. Figure 11.7 provides a schematic view: the wiggly curve fluctuates around a smoother trend. The two curves below are constructed functions, not fitted neural networks or empirical estimates of bias and variance.

11.4.6.2 Common Regularization Techniques

Among the simplest and most widely used techniques is L2 weight decay, which adds a penalty term to discourage large weights:

\[ L_{\text{total}} = L_{\text{data}} + \lambda \sum_{l}\sum_{i,j} (w_{ij}^{(l)})^2, \]

where \(L_{\text{data}}\) is the data loss, \(L_{\text{total}}\) is the penalized loss, \(\lambda \geq 0\) controls penalty strength, and \(w_{ij}^{(l)}\) is the weight from neuron \(j\) to neuron \(i\) in layer \(l\). The sum runs over all weight matrices and their entries. Other general approaches include dropout, which randomly deactivates neurons during training to prevent reliance on any single pathway, and early stopping, which halts training once the validation loss stops improving. These ideas apply to networks of all depths and form the foundation for more advanced regularization strategies in deep learning.

NoteWhy Regularization Works

Regularization methods restrict how freely the model parameters can adapt to training data. This constraint encourages smoother mappings, reduces sensitivity to noise, and improves generalization to unseen inputs.

TipPractical Tips
  • Start with small \(\lambda\) for L2 weight decay.
  • In implementations supporting dropout, try a dropout probability \(p\) between 0.2 and 0.5 for dense layers. Scikit-learn’s MLPClassifier does not implement dropout.
  • Always track training vs. validation loss curves to detect overfitting.

11.4.7 Example: A Simple Feed-Forward Network

To illustrate how a neural network operates in practice, we train a simple multilayer perceptron (MLP) on a two-dimensional nonlinear dataset. The model learns a curved decision boundary that cannot be captured by linear classifiers.

The two-moons dataset consists of two interleaving half-circles, forming a pattern that resembles a pair of crescents. Each point represents an observation with two features \((x_1, x_2)\), and the color indicates its class. The two classes overlap slightly due to added random noise.

A linear classifier such as logistic regression would draw a straight line through the plane, misclassifying many points. In contrast, a neural network can learn the nonlinear boundary that curves along the interface between the moons. This problem, although simple, captures the essence of nonlinear learning in higher dimensions.

We generate the data using make_moons() from scikit-learn and train a feed-forward neural network with two hidden layers. The model’s task is to assign each observation to one of the two moon shapes.

import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.neural_network import MLPClassifier

# Generate synthetic data
X, y = make_moons(n_samples=500, noise=0.25, random_state=2026)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=2026, stratify=y)

# Define and train a small neural network
mlp = MLPClassifier(hidden_layer_sizes=(10, 5),
                    activation='relu',
                    solver='adam',
                    alpha=0.001,
                    max_iter=2000,
                    random_state=2026)
_ = mlp.fit(X_train, y_train)

After the model is trained, we evaluate its accuracy. Both classes are equally represented in each split, so predicting the same class for every observation would give 50% accuracy. Accuracy is useful for this balanced example, while the imbalanced-data discussion explains why it may be inadequate in other settings.

# Evaluate accuracy
acc_train = mlp.score(X_train, y_train)
acc_test = mlp.score(X_test, y_test)

# Prepare grid for decision boundary
xx, yy = np.meshgrid(np.linspace(-2, 3, 300),
                     np.linspace(-1.5, 2, 300))
Z = mlp.predict(np.c_[xx.ravel(), yy.ravel()]).reshape(xx.shape)

# Plot
fig, ax = plt.subplots(figsize=(6, 5))
ax.contourf(xx, yy, Z, cmap="coolwarm", alpha=0.3)
scatter = ax.scatter(X_train[:, 0], X_train[:, 1], c=y_train, cmap="coolwarm", edgecolor="k", s=40)
ax.set_xlabel("$x_1$")
ax.set_ylabel("$x_2$")
ax.set_title(f"Two-Moons Classification (Train Acc: {acc_train:.2f}, Test Acc: {acc_test:.2f})")
plt.show()

Compare the training and test accuracies shown in the figure title. High test accuracy supports prediction on fresh observations from this simulation, while a large training-test gap would suggest overfitting. The contour regions in Figure 11.8 reveal the curved boundary the network has learned. Each hidden layer transforms the input coordinates into a new representation where the two classes become more separable. After a few layers of nonlinear transformations, the output layer can classify the points with a simple linear threshold.

Note

Even this small network, with 91 trainable parameters, can learn a highly nonlinear decision surface. This illustrates the expressive power of multilayer neural networks, even in low-dimensional spaces.

TipTry It Yourself

Increase the noise level in the data to test robustness. Change the hidden layer sizes (e.g., (3,), (20,10)), or the activation function (tanh, logistic). Adjust the regularization parameter alpha to see how it affects smoothness of the boundary.
